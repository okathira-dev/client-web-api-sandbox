# レーザー検出検証PoC

Webカメラでディスプレイを撮影し、おもちゃの赤色レーザー銃の着弾点をブラウザだけで検出する方式を、技術選定のために比較・検証するプロトタイプです。ゲーム本体ではなく、補正と検出のパターンを実機条件で振って比べるための実験ベンチです。

## できること

- 検出方式6種（単純RGB / HSV赤 / 輝度飽和 / 時間差分 / 理想差分（実験） / 複合）を同じフレームに同時実行し、マスク・検出座標・処理時間で比較
- 補正の切り替え（ホモグラフィ正面化・ぼかし・色度正規化・背景モデル差分）とパラメータの即時変更
- 4点手動キャリブレーションによる画面領域の正面化
- テストパターン表示（静止ターゲット、格子 5×4、移動ターゲット、白画面、赤多め、同期カウンタなど）
- 格子点での位置誤差の記録（px / 画面対角比%）と、測定結果のJSONダウンロード
- 実カメラの capabilities / settings 表示、露出・ホワイトバランス固定の試行、`requestVideoFrameCallback` のメタデータ表示

## 使い方

1. ページを開くと模擬カメラ（画面を斜めから撮った合成映像＋模擬レーザー）で始まります。実カメラが無くても、検出方式の比較やキャリブレーションの流れはそのまま試せます。
2. 実カメラを使う場合は「実カメラを開始」を押し、カメラをディスプレイに向けて固定します。
3. 画面の隅4点を順にクリックしてキャリブレーションし、正面化された映像で検出を確認します。
4. 表示パターンや検出方式・パラメータを切り替え、格子パターンで誤差を記録し、JSONで書き出して比較します。

## 注意

- 実カメラ（getUserMedia）には secure context が必須です。`https` のURLか `http://localhost` でページを開いてください。ファイルを直接開いたり、LAN内IPの `http` で開いたりするとカメラは使えません（その場合も模擬カメラでの検証は可能です）。
- 映像はブラウザ内でのみ処理され、外部に送信されません。
- レーザーはクラス1 / クラス2の正規品を使い、目に向けないでください。検出に必要なのは出力ではなく、暗めの環境と露出設定によるコントラストです。

## 実装メモ

- 単体HTMLの検証ページを移植したもので、`index.html` + `main.ts` + `style.css` の vanilla 構成です。`main.ts` は移植元コードの挙動を変えないことを優先し、`@ts-nocheck` と一部ルールの `biome-ignore` を付けています。検出方式が固まった段階で型付けと整備を行う想定です。
- 外部フォント（Google Fonts）以外に外部依存はありません。

# Edgeモバイルアップロード用ファイル転送

Microsoft Edgeの「モバイルからアップロード」を使うためだけの、ファイル受け取り専用ページです。

## 機能

- 標準のファイル選択（`<input type="file" multiple>`）だけを持つページ
- 選択したファイルの一覧表示（ファイル名・サイズ）
- 各ファイルの手動ダウンロード（Blob URL経由）

このページからファイルをサーバーへ送信することはありません。選択したファイルはブラウザー内の一覧で保持し、一覧のクリアやページを閉じる操作で破棄します。ダウンロードして保存したファイルは削除されません。Edge自体が行うモバイル転送の通信経路を保証するものではありません。

## 使用方法

1. PCの Microsoft Edge でこのページを開きます
2. PCとスマートフォンを同じWi-Fiに接続します
3. 「ファイルを選択」を押します
4. Edgeの「モバイルからアップロード」を選び、表示されるQRコードをスマートフォンで読み取ります
5. スマートフォンでファイルを選び、転送します（1回10ファイルまで・1ファイル1GBまで）
6. 受け取ったファイルを一覧で確認し、「ダウンロード」から保存します。このページから自動保存は行いません

PC内のファイルを普通に選択した場合も、そのまま一覧からダウンロードできます。

モバイル転送の条件は[Microsoft公式の説明](https://www.microsoft.com/edge/features/mobile-upload)を参照してください。ブラウザーのバージョンや管理ポリシーによっては項目が表示されないことがあります。

## ローカル検証（2026-11-01）

- `npm run check`、`npm run test:ci`（24スイート222件）、`npm run build`が成功。
- 一時的なJSDOM環境で、StrictMode下の複数・空・同名ファイル追加、サイズ表示、キャンセル、ダウンロード先と保存名、同じファイルの再選択用リセット、クリアとアンマウント時のBlob URL解放を確認。
- Chromeで初期画面と複数ファイル選択ダイアログの起動を確認。Enterで開かなかった選択ボタンを標準のbutton要素に修正し、クリックからfile inputが起動することをDOM検証。
- EdgeのUI操作は、自動操作ツールが現在URLを安全に判定できず停止。Edge固有メニュー、QR接続、スマートフォンからの転送、実ファイルの保存完了は未確認。
- 修正後のキーボード実操作、長いファイル名・狭い画面の表示は、実ブラウザーでの再確認が必要。

# S-790 Busybox Key font

`assets/busybox-key.ttf` is a deterministic, project-original TrueType-flavoured OpenType fixture. It is generated by `scripts/generate-busybox-s790-font.mjs`, is not derived from a third-party font, and contains only space plus the dedicated `U+E000` key glyph.

The stage downloads this file for installation through the operating system. It then calls `queryLocalFonts({ postscriptNames: ["BusyboxKey-Regular"] })`, verifies the exact generated SHA-256 digest, constructs a `FontFace` from `FontData.blob()`, and renders `U+E000`.

Regenerate with the repository's pinned Node runtime:

```powershell
node scripts/generate-busybox-s790-font.mjs
```

# S-910 runtime WebVTT fixture

`assets/caption-stage.webm` is a dedicated, Git-managed 640×360, 15fps VP8 reel generated by FFmpeg. The red circle, blue triangle, and yellow square are pixels encoded into the video at the cue intervals in `generation-manifest.json`; CSS does not supply the symbols. The player still creates the captions with runtime `VTTCue` objects, so no prerecorded caption file participates in the puzzle.

Regenerate the fixed asset only with:

```powershell
$env:BUSYBOX_FFMPEG_PATH = "<trusted-ffmpeg-path>"
$env:BUSYBOX_FFPROBE_PATH = "<trusted-ffprobe-path>"
node scripts/generate-busybox-s900-s910-fixtures.mjs
```

`assets.test.ts` verifies the FFmpeg probe metadata and that the encoded visual schedule remains aligned with the runtime cue schedule.

As with S-900, the generator normalizes FFmpeg's randomized WebM `TrackUID` after encoding so identical inputs are byte-for-byte reproducible. No separate checksum registry is maintained.

# 元仕様からの対象範囲

この機能は、もともと Chrome 拡張（録画アプリ）の一部として書いたものを、拡張 API に依存しない独立した Web アプリとして書き直したものである。

元仕様書のうち、**3.6「録画設定への反映」と 3.7「録画時の再検証」は対象外**とする。このリポジトリには録画機能そのものがなく、検査結果を反映する先が存在しないためである。

実装しないもの:

- 検査結果による録画設定のコーデック選択のゲーティング
- 録画開始直前の、実際の録画条件（解像度・FPS・ビットレート・音声 ch・コンテナ）での再検証
- 録画開始要求による検査の自動停止、録画中の検査開始禁止

一方、元実装で未達だった音声候補の多重化（仕様 3.1-4）は実装済みである。AAC は mp4、Opus は webm へ実際に書き出して検証する。
